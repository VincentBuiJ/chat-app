
# Real-Time Chat Application

A simple chat app that allows two users to send and receive messages in real time using sockets.

## Features

- Real-time messaging
- Two users chatting in separate browser windows
- Different colors for each user's messages

## How It Works
1. The server connects users using sockets.

2. Each user opens the app in a browser.

3. Messages are sent through the server.

4. Messages appear instantly without refreshing.

5. Each user's messages have a different color.

## How to Run

1. Clone or download the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in two separate browser windows.
   
5. Select a different user (A or B) in each window and start chatting.

## Technologies

- Node.js
- JavaScript
- Sockets
- HTML and CSS
